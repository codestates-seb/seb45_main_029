## 🔍 주요 기능
### 1. 맞춤형 운동 추천
- 사용자 선호도 기반 운동 영상 자동 저장
- 개인화된 알고리즘 기반 운동 추천
- 운동 히스토리 관리 및 분석

### 2. 사용자 인증
- 이메일 기반 회원가입/로그인
- 토큰 기반 인증 시스템
- 사용자 정보 유효성 검증

### 3. 커뮤니티
- CKEditor 기반 게시판 CRUD
- 실시간 댓글 시스템
- 동기부여 페이지
